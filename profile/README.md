## What this is

Self-hosted spaces where presence is a **rhythm**, not a timestamp.
Where the room ends by absence. Where "I left" is the same as
"I was never here."

No central accounts. No telemetry. No presence tracking by time.
No green dot. No "last seen." No read receipt. No badge count.

The garden doesn't remember. You do.

## The Test

> *"If I remove this, can someone verify whether another person is home?"*
>
> If yes → remove it.
> If no → it stays.

This is the filter for every feature, every PR, every UI element.
It is not a setting. It is a **physics.**

---

## Design Principles

| Principle | What it means |
|---|---|
| **Zero memory** | No log. No history. No "last seen." The room state = current signals only. |
| **Zero attribution** | No "X joined." No "X left." The circle changes. That's it. |
| **Fire-and-forget** | Signals are not acknowledged, not buffered, not retransmitted. |
| **Broadcast, not query** | You can announce presence. You cannot verify absence. |
| **Geography, not settings** | Room type = space. You choose the room, not the config. |
| **Degradation = depth** | Network instability makes the breath slower, not the connection "worse." |
| **Residue = co-dependence** | A persistent fact is a hook. No hook. No co-dependence. |

Full spec: [RFC-001 — Presence Physics](https://github.com/GratiaOS/portal/blob/main/docs/rfc-001-presence-physics.md)
